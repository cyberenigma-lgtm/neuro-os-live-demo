👑 Sovereign Ring-0 Kernel

Ultra-compact ~515 KB stripped ELF64 (kernel_x64.elf). Boots bare-metal with Multiboot1/2, GDT64, IDT64, and isolated per-process CR3 PML4 page tables.

🛡️ Ring-3 Privilege Separation

Enforces strict unprivileged user mode (CPL=3, UID=1000). Kernel critical paths reject writes with -EACCES. Root escalation blocked with -EPERM.

🎨 Quartz-Compiz Compositor

Custom 2D/3D hybrid software compositor. Direct framebuffer rendering to /dev/fb0 with multi-window dragging, z-order layering, and real GTK3/Cairo UI widgets.

📦 Multi-ABI Capsule Subsystem

Direct userspace binary execution without full guest VMs: Linux ELF64 POSIX layer, Win64 PE64 capsule loader, in-memory RAMFS, and native logical dispatch.
